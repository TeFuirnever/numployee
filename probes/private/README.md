# probes/private/ —— 私有保留集（占位）

本目录**故意为空**。它是「私有保留集」的约定位置：用于防作弊审计的探针变体不应提交到公开仓库（公开即失效），而应存放在部署方自己的私有位置，并按最小访问控制分发。

约定：

1. 私有集中的题目遵循 `../probes.md` 的题目结构与 `variant_of` 派生关系（母题在公开集）；
2. 合规声明引用私有集结果时，证据包（`../EVIDENCE.md`）中题目内容可脱敏，但判定程序、配置哈希与双评审留痕不可省略；
3. 开放性与防作弊的取舍须在你的合规档案中显式声明（SPEC 7.5）。

为什么存在这个空目录：让「私有保留集」成为标准里一个**有名字的接口**，而不是一句倡议——工具链与文档可以稳定地指向它。
