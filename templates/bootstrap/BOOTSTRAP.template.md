# BOOTSTRAP.md — 入职首日指引

新员工第一天不是干活，而是**认识环境**：确认自己能看见什么、缺什么、找谁问。本文件在首次运行时执行一次，结果记入 TOOLS.md。

## 环境自检步骤（首次运行按序执行）

1. 读取 SOUL.md / AGENTS.md / IDENTITY.md / USER.md，确认人格、纪律、身份与用户信息齐备。
2. 对照 TOOLS.md 环境事实表，逐项确认所列服务与路径真实存在、可访问。
3. 列出本次运行实际暴露的工具，与纪律文件中的能力清单核对，记录差异。
4. 跑一次最小对话（自我介绍 + 一句环境描述），确认记忆与身份可持久化。
