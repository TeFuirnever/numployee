# RB06 从市场下载员工模板 & 发布自己的员工

> 本文是通用机制 runbook；界面入口与文案以你的客户端为准，配套参考实现见 [implementations/openclaw/](../../implementations/openclaw/MAPPING.md)。

**一句话目的**：从"员工市场"一键下载别人发布的员工，或把自己的员工发布出去分享。

**适用场景**：想直接用成熟模板；或想让自己调好的员工被同事使用。

**前提准备**：下载需有员工市场访问权限；发布需你是该员工的 owner（黄区上传权限的唯一依据）。

**A. 下载（下载即实例化）**：

1. 进侧边栏"员工市场"，找到想要的员工，打开详情。预期：看到"下载"入口。
2. 点下载。预期：界面给出类似"下载员工成功"的提示（参考实现文案），随后自动"转化为数字员工"——下载完就有可启用的员工，不用手动再建一遍。
3. 到"我的员工"里启用它，按 RB01 第 5 步发起对话。预期：员工正常回复。

**B. 发布**：

1. 在"我的员工"里确认员工已调好（描述、技能、人格都满意，见 RB07）。
2. 确认你是 owner；不是 owner 没有上传权限。预期：owner 可见"上传员工"入口。
3. 点上传，阅读发布确认（发布后该数字员工，含全部 MD 文件内容，将对市场所有用户公开），确认发布。预期：市场上出现你的员工卡片。
4. 后续更新：改完本地员工重新上传。上传的员工 id 与导出文件 `role-info.json` 里的 id 同源；市场条目的版本号是员工版本的唯一来源。

**怎么验证成了**：下载侧——"我的员工"里出现新员工且能对话；发布侧——在市场搜到自己的卡片，版本号与本地一致。

**常见问题**：

- Q：更新市场员工后，我之前本地改的没了？A：市场更新是**全量覆盖**，你在本地未发布过的修改会被模板版本整个盖掉；有本地定制就别点更新，或先把定制发布出去。
- Q：卡片显示"点击更新"但我没改过本地？A：放心更新，全量覆盖对无本地修改的员工是安全的。
- Q：为什么看不到"上传员工"？A：该员工不支持上传，或你不是 owner。
