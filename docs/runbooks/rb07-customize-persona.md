# RB07 定制员工的人格

> 本文是通用机制 runbook；界面入口与文案以你的客户端为准，配套参考实现见 [implementations/openclaw/](../../implementations/openclaw/MAPPING.md)。

**一句话目的**：在客户端里改员工的描述和指令层，让它按你想要的性格和边界说话。

**适用场景**：嫌员工说话太死板、想给它立人设、想规定它哪些事不做。

**前提准备**：已创建员工（RB01）；能进入员工编辑界面。

**操作步骤**：

1. 在"我的员工"里找到它，点"编辑"。预期：打开"修改数字员工"窗口。
2. 修改描述字段：写清身份、语气、边界，例如"你是耐心的客服，先给结论再展开，不编造没有的功能"。预期：提示修改成功。
3. 保存后**新开一个对话**验证。预期：员工的自我介绍和回答风格与新描述一致。

**进阶说明**：客户端界面里只能改指令/描述这一层。更深的人格文件（`SOUL.md`、`AGENTS.md`、`TOOLS.md` 等，由系统的受管模板同步到持久 workspace——该产品的受管块同步机制：模板在其提示词增强模板目录中，同步到 `~/.openclaw/workspace/`）属于进阶玩法，改错会影响全部员工，见进阶手册，本 runbook 不展开。

**怎么验证成了**：新开对话问"你是谁、做事有什么规矩"，回答符合新描述；再故意问一个你规定"不做"的事，它被婉拒。

**常见问题**：

- Q：改了没变化？A：旧对话带着旧上下文，新建对话再测；仍不行就检查是否保存成功。
- Q：能只给某一个员工换人格吗？A：可以，客户端里的描述/指令是每员工独立的；SOUL 级文件是全局的，改前想清楚。
- Q：改完说话怪怪的想还原？A：员工版本里有历史记录，可回滚到之前的版本。
